# Outfit Font Files

Download the Outfit font from Google Fonts (open licence / SIL OFL):

1. Go to https://fonts.google.com/specimen/Outfit
2. Click **Download family**
3. Unzip and copy these files into this `res/font/` directory:

   - `Outfit-Thin.ttf`    → rename to `outfit_thin.ttf`
   - `Outfit-Light.ttf`   → rename to `outfit_light.ttf`
   - `Outfit-Regular.ttf` → rename to `outfit_regular.ttf`

The `05_build_install.ps1` script will remind you if the files are missing.
